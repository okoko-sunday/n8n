TEAM PHOTOS
===========

Put team member photos in this folder.

Photo guidelines
- Square images (same width and height), at least 400 x 400 pixels.
- Format: JPG, PNG or WebP.
- File size: under 300 KB each (compress at https://squoosh.app if needed).
- Use simple lowercase file names with no spaces, e.g. sunday.jpg, ada-obi.webp

After adding a photo
1. Open js/team.js.
2. Find the person in the TEAM list at the top of the file.
3. Set their "photo" value to the path of the file, e.g.
     photo: "images/team/sunday.jpg"

Notes
- File names are CASE-SENSITIVE once the site is online:
  "Sunday.JPG" and "sunday.jpg" are different files.
- If a photo is missing or the path is wrong, the page shows a coloured
  circle with the person's initials instead of a broken image.
